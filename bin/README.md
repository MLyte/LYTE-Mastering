# Bundled Windows audio runtime

This directory contains the unmodified PhaseLimiter v0.2.0 Windows executable and its 11 matching DLLs, plus FFmpeg 8.1 from the existing local Gyan essentials installation.

PhaseLimiter provenance and SHA-256 hashes: ../resources/phaselimiter/runtime-manifest.json.
PhaseLimiter notices: ../resources/phaselimiter/LICENSE and licenses/.
FFmpeg notices and build configuration: licenses/ffmpeg/.

These files are bundled in the local Windows installer. The application does not download executables at runtime. See ../THIRD_PARTY.md before public redistribution.
