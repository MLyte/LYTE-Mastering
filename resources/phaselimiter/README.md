# PhaseLimiter resources

Place the **file** `sound_quality2_cache` from the matching Windows release's `phaselimiter/resource/` directory here. This is serialized analysis data, not an empty directory and not the text cache for ProMeter.

You can copy the full upstream resource directory, including license notices. No cache is fabricated. The application passes the absolute cache filename to `--sound_quality2_cache`.
